# SURF BASE - 海天気 × ナウファス実測ダッシュボード

福井エリア（水晶浜・菅浜・黒崎・越前リーフ）専用のサーフィン予報・実測答え合わせ＆波レポ蓄積ダッシュボードです。

## 特徴
- **海天気.jp × ナウファス実測 答え合わせ**: 予報と実測のズレを一目で確認可能
- **1時間単位の波レポート登録**: 海上がりに各時間の波サイズ＆Rateを個別登録
- **GitHub Actionsによる自動取得**: 1時間ごとに最新のナウファス実測と海天気予報をクラウドが自動スクレイピング・更新
- **PWA・スマホ最適化**: スマートフォンのホーム画面に追加してアプリ感覚で利用可能
